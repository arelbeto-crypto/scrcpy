POCO V5 RUNTIME CONTROLS

Esta version compila el cliente con atajos nuevos para controles Camera2 que ya estaban disponibles internamente en V3/V4.

Nuevos atajos:
- Alt+F / Alt+Shift+F: FPS siguiente/anterior
- Alt+G / Alt+Shift+G: antibanding siguiente/anterior
- Alt+M / Alt+Shift+M: modo AF siguiente/anterior
- Alt+N / Alt+Shift+N: noise reduction siguiente/anterior
- Alt+E / Alt+Shift+E: edge/nitidez siguiente/anterior
- Alt+P / Alt+Shift+P: tonemap siguiente/anterior
- Alt+C / Alt+Shift+C: correccion de distorsion siguiente/anterior
- Alt+X / Alt+Shift+X: efecto siguiente/anterior
- Alt+I: mismo diagnostico que Alt+H

El build aplica release/poco/APPLY_V5_RUNTIME_PATCH.py antes de compilar y testear el cliente.
